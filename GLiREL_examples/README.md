# GLiREL Multilingual Relation Extraction

Demonstrates multilingual relation extraction using [GLiREL](https://github.com/jackboyla/GLiREL) on 10 exemplary sentences covering geography, history, and science in both English and German.

## Model

GLiREL (Generalist and Lightweight model for Zero-shot Relation Extraction) is a zero-shot relation extraction model that identifies arbitrary relations without requiring fine-tuning on specific relation types. The architecture uses a pre-trained DeBERTa V3-large encoder to jointly process candidate relations and input texts, an entity pair representation module to extract vector representations for all entity pairs, and a scorer module to compute similarity between entity pairs and relation labels in a shared latent space. Unlike traditional classification-based approaches, GLiREL's shared embedding space enables flexible relation extraction across multiple languages at inference time.
